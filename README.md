# SpecForge

ソースコードを解析して、日本語の設計書（Excel）を生成する Windows 用ツールです。
AI は使わず、ルール・辞書・文型で処理するため、社外にコードを送りません。

## ダウンロード
[SpecForge_v0.1.0.zip](SpecForge_v0.1.0.zip) をダウンロードしてください（ファイルを開いて「Download raw file」）。
ZIP はパスワード付きです。パスワードは担当者から別途お知らせします。

## 使い方
1. ZIP を展開（パスワードを入力）
2. `SpecForge` フォルダー内の `SpecForge.exe` をダブルクリック
3. 解析したいフォルダーを読み込み →「① 解析」→「② 生成」

Python などのインストールは不要です（Windows 10 / 11 64bit）。
詳しくは展開後の `使い方.txt` をご覧ください。

## 出力できる設計書
画面設計書 / API設計書 / 帳票設計書 / 一括処理設計書 / 共通処理設計書

## 対応言語
Java / Kotlin / C# / JavaScript / TypeScript / Vue / Python / VBA / PL/SQL / SQL / MyBatis XML / HTML（Thymeleaf・JSP）
